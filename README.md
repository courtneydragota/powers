# powers

<!-- badges: start -->

<!-- badges: end -->

The goal of powers is to help people calculate powers of any number

## Installation

You can install the development version of powers like so:

``` r
`devtools::install_github("courtneydragota/powers")`
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(powers)
## basic example code
square(c(2,4,5))
#> [1]  4 16 25
```
